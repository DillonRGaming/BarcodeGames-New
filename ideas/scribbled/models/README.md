# Models

One folder per item, named by its id in `../items.json`:

```
models/
  ming-vase/
    model.glb      the 3D model (glTF binary)
    LICENSE.txt    where it came from and its licence
```

Scale: 1 unit = 1 metre. The item stands on the stool's seat at y = 0, centred on x and z.

Also wanted for the room itself (replacing the code-drawn versions):
- `room/stool.glb`: a tall square wooden stool, about 78 cm
- `room/bench.glb`: a long low gallery bench
- `room/parquet/`: a parquet floor texture set (colour, roughness, normal)
